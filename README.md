# Employee Management System

A full-stack Employee Management System built using React, Express.js, and MySQL.

---

## 🚀 Backend API Requirements
Implement REST API endpoints to perform CRUD operations:

* **POST** `/api/employees` - Add a new employee
* **GET** `/api/employees` - Retrieve all employees
* **GET** `/api/employees/:id` - Retrieve one employee
* **PUT** `/api/employees/:id` - Update an employee
* **DELETE** `/api/employees/:id` - Delete an employee

---

## 🎨 UI/UX Requirements
* Create a clean, user-friendly interface.
* Make the application responsive on desktop and mobile devices.
* Provide clear form validation messages.

---
